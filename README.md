# Flowboard

Flowboard is a local project task board for keeping personal work organized.

## Requirements

- Node.js 20.19 or newer
- npm

## Run locally

Install dependencies, then start the Vite development server:

```sh
npm install
npm run dev
```

## Production build

Run the TypeScript check and create a production bundle:

```sh
npm run build
```

To preview the production bundle locally:

```sh
npm run preview
```
